# Editorial logs

One file per chapter, named after the chapter file: `NN-<slug>-editorial-log.md` (for example `05-mcp-server-editorial-log.md` for `manuscript/05-mcp-server.md`). Each log records the passes the chapter went through (draft, technical check, line edit, final read), when, and what each pass checked or changed. The findings themselves, with their sources, go into the chapter's table in [`VALIDATION.md`](../VALIDATION.md).
