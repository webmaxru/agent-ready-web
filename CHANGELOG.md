# Changelog

All notable changes to *Agent-Ready Websites in Action* are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/) as read for a book (see [RELEASING.md](RELEASING.md)).

Each version is a Git tag `vX.Y.Z`. Its GitHub Release carries the PDF, the print PDF, the EPUB and the HTML edition built from that tag. The web edition shows this file as its release history and as the Atom feed `releases.xml`.

## [2.0.0] - 2026-11-05

### Added

- The manuscript of *Agent-Ready Websites in Action*, as listed in `manuscript/Book.txt`: a preface, About this book, 12 chapters in three parts (Seen and read, Letting agents act, Trust and production), appendices A–D (a checklist by role, files, headers and standards at a glance, pay per crawl and content licensing, a glossary and resources) and About the author. About 106,300 words, 37 figures, 358 pages in the PDF.
- Chapter 11, "Two ways to buy: in-page tools or a protocol checkout", on WebMCP tools and a UCP checkout side by side: which channel an agent should use, whether the human-in-the-loop guarantees carry over, and which record a dispute relies on. Thanks to Francesco Marinoni Moretto for the question.
- A validation table for every chapter and appendix (`validation/`, summarised in VALIDATION.md), with the source and retrieval date of every claim. A claim that could not be verified against a primary source is not in the book.
- The demos for every chapter in [webmaxru/agent-ready-web-demos](https://github.com/webmaxru/agent-ready-web-demos/releases/tag/v2.0.0) v2.0.0: Nordlys Cabins, made agent-ready one layer per chapter, with layer folders, tests and standalone demos numbered by chapter (Table 0.1 in About this book).
- The PDF (7 × 9.25 in), the paperback interior for KDP (7.5 × 9.25 in), the EPUB and the HTML edition.
